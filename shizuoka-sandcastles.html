Shizuoka Prefecture Geospatial Analysis Demos

Interactive CesiumJS visualizations for geospatial data analysis, disaster response, and change detection

Abe River Flood Response

Interactive dashboard for real-time flood response along the Abe River. Visualizes flood extent, evacuation routes, emergency shelters, and river flow patterns with guided tour of critical response areas.

Point Cloud vs. Buildings

Comparative visualization of LiDAR point cloud data against 3D building footprints. Demonstrates layer comparison, transparency controls, and accessibility features for spatial data exploration.

Voxel Analytics

3D voxel-based spatial analytics for water saturation and bathymetry analysis. Interactive voxel picking, vertical reveal controls, and guided tour demonstrating volumetric data exploration techniques.

Time-Series Point Cloud Change
